## Установка среды выполнения

**Условие:** на рабочей станции есть права администратора.

**Действие:**

1. Установите Python 3.9+ с официального сайта ([https://www.python.org/downloads/](https://www.python.org/downloads/)). При установке на Windows отметьте «Add Python to PATH» либо укажите полный путь к `python.exe` в скриптах запуска.
2. Установите PostgreSQL 13+ и запомните пароль пользователя `postgres` (или создайте отдельного пользователя для приложения).
3. Убедитесь, что служба PostgreSQL запущена и порт 5432 доступен.

**Ожидаемый результат:** команды `python --version` и `psql --version` выполняются без ошибок.

## Пошаговая установка (Windows)

### Размещение проекта

**Условие:** на компьютере есть каталог для установки (например, `Downloads`).

**Действие:** скопируйте папку проекта, например:

```
C:\Users\zaych\Downloads\mahazine
```

**Ожидаемый результат:** в каталоге присутствуют файлы `main.py`, `database.py`, `config.py`, `requirements.txt`.

### Создание виртуального окружения и установка зависимостей

**Условие:** Python 3.9+ установлен и доступен в командной строке.

**Действие:**

1. Откройте **cmd** в каталоге проекта.
2. Создайте виртуальное окружение:

```bat
python -m venv venv
```

3. Активируйте окружение и установите зависимости:

```bat
venv\Scripts\activate
pip install -r requirements.txt
```

**Ожидаемый результат:** в начале строки появляется `(venv)`; пакеты `flet`, `psycopg2-binary`, `Pillow` установлены без ошибок.

### Создание и настройка базы данных

**Условие:** PostgreSQL установлен и запущен.

**Действие:**

1. Подключитесь к серверу:

```bat
psql -U postgres
```

2. Создайте базу данных:

```sql
CREATE DATABASE shoe_store;
```

3. Выполните SQL-скрипты инициализации схемы и начальных данных проекта.

**Ожидаемый результат:** база `shoe_store` существует, в ней есть необходимые таблицы и справочник ролей.

### Настройка config.py

**Условие:** проект размещён в каталоге установки.

**Действие:** откройте файл `config.py` в текстовом редакторе и укажите параметры подключения к PostgreSQL (host, port, database, user, password).

Пример структуры:

```python
DB_CONFIG = {
 "host": "localhost",
 "port": 5432,
 "database": "shoe_store",
 "user": "postgres",
 "password": "your_password",
}
```

**Ожидаемый результат:** файл сохранён; значения соответствуют реальному серверу БД.

### Первый запуск

**Условие:** Python установлен, `config.py` настроен, БД `shoe_store` создана, зависимости установлены в `venv`.

**Действие:**

1. Перейдите в каталог проекта.
2. Активируйте виртуальное окружение:

```bat
venv\Scripts\activate
```

3. Запустите приложение:

```bat
python main.py
```

**Ожидаемый результат:** после запуска откроется окно приложения с формой «Вход в систему» (поля «Логин», «Пароль», кнопки «Войти» и «Войти как гость»).
