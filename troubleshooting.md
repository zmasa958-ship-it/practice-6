## Типичные проблемы

| Признак | Возможная причина | Что делать |
|---------|-------------------|------------|
| `ModuleNotFoundError` / приложение не запускается | не активирован venv; нет пакетов | `venv\Scripts\activate`, затем `pip install -r requirements.txt` |
| Ошибка подключения к БД | PostgreSQL остановлена; неверный `config.py` | Запустить службу: `net start postgresql-x64-15`; проверить host, port, user, password |
| `password authentication failed` | неверные учётные данные БД | Исправить user/password в `config.py` |
| `relation "tovar" does not exist` | схема БД не создана | Выполнить скрипты инициализации базы `shoe_store` |
| Пустой каталог товаров | нет данных или ошибка запроса | Проверить `SELECT` в БД; права роли |
| Не отображаются изображения | нет файлов в `assets` | Проверить `assets/images/tovar/` |
| Нельзя удалить товар | товар связан с заказами | Удалить из заказов, затем повторить |
| Свободного места на диске менее 15 % | диск заполнен | Очистить `%TEMP%`, старые логи и дампы |

## Контрольный список диагностики

1. Активирован ли **venv**?  
2. Выводит ли `python -c "import flet, psycopg2, PIL; print('OK')"` значение `OK`?  
3. Служба PostgreSQL в состоянии **RUNNING**? (`sc query postgresql-x64-15`)  
4. Успешна ли команда `psql ... -c "SELECT 1;"`?  
5. Верны ли значения в **config.py**?  

Подробные команды — в разделе [Справка](reference.md).
